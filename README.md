# FaultDesk

Turns customers' free-text vehicle-fault descriptions into something a service adviser and workshop can act on:
structured triage, similar past tickets (SQL Server 2025 vector search) and an AI-generated investigation plan.

Built for a technical assessment in .NET 10 / Blazor Server with a domain-driven project layout.

Work in progress. The approved plan and commit sequence are in [docs/plan.md](docs/plan.md).
Build and run instructions land with the deployment commit.
